MISUC — UI IMPLEMENTATION PLAN  (Master UI/UX Specification, §0–§83)
================================================================================
Date:       2026-09-07
Authority:  MISUC_UI_MASTER_SPEC (§0–§83) supersedes the earlier Phase-1-only
            scope. The full modular DAW GUI is in scope now (§1: Playlist,
            Channel Rack, Piano Roll, Mixer, Browser, Inspector, Plugin windows
            are first-class, NOT postponable placeholders).
Golden rules:
  * Preserve the working audio foundation (§48) — the engine is NOT modified.
  * Keep every existing test green: engine tests (misuc_tests) + the UI
    harness (prbehave) must remain green after every stage (§63, §81).
  * No fake features (§49): every new workspace has a real model/view or an
    honest, documented boundary; never fabricate playback/DSP/windows.
  * Charcoal-black + smoked glass + restrained violet accents (§36-38, §44).
  * Icon-first (§6, §79): glyphs without permanent text where possible; the
    CommandRegistry is the single source of truth for shortcuts, tooltips,
    Hint Bar and menus (§7, §51, §78).

1. BASELINE (already delivered, remains the foundation)
-------------------------------------------------------------------------------
- Shell: MainWindow = QMainWindow; HeaderBar (QToolBar) top = brand cluster
  (navLogo+wordmark+project) | TransportBar | live status cluster (CPU/RAM from
  /proc, sr, buffer+latency, xruns, state, mini meters). Central QTabWidget
  (Project|Editor|Audio|Appearance). Mixer in QDockWidget. HintBar + StatusPanel
  in QStatusBar. Workspace presets + QSettings layout persistence. F7/F9/Space.
- Theme: theme::k* tokens + ThemeEngine (8 presets, custom accent, glass,
  QSS, .misuctheme + QSettings persistence, all paint-time token driven).
- HintSystem: HintBar + HintManager (per-widget event-filter registry).
- Contract (must never break): MainWindow::session()/sessionEdited()/
  setExportPathOverride()/writeProject()/openProject(); menu actions
  "Export &Audio..." and "&About Misuc..."; QLabel objectName "navLogo" with
  pixmap width > 20; the FIRST QListWidget in the window stays the editor track
  list (nothing may add a QListWidget before EditorPage is created); MixerPage/
  ChannelStrip/Fader findChildren + master-fader-semiclassification; ThemeEngine
  accent-equality; PianoRoll pixel-identical defaults at stock theme.
  Carets/loop use theme::kPlayhead/kLoopRegion tokens; velocity bars, selection
  and OK-status stay theme::kOk.

2. TARGET ARCHITECTURE (per master spec)
-------------------------------------------------------------------------------
Workspaces (each a real widget, dockable/floating/visible via VIEW + header
strip + shortcuts):
  * Playlist    (central, largest): track lanes + timeline ruler + violet
                playhead; real Session clips rendered per type
                (audio/MIDI/pattern/automation) with distinct visual language;
                real edit ops (select/move/Ctrl+D/delete/rename/mute/snap,
                resize-right, trim-left, split) driving Session + undo.
  * Piano Roll  (EditorPage, dockable): existing 1320-line editor kept intact;
                caret now uses violet theme::kPlayhead.
  * Channel Rack: real model/view (QAbstractItemModel) starter lineup
                Kick/Snare/Hi-Hat/Bass/Sampler; step sequencer (16 steps),
                per-channel volume/pan/mute/solo, add/remove/rename/duplicate.
                Honest boundary: step-pattern audio output requires engine
                pattern playback (future) — documented, no fake audio.
  * Mixer       (existing MixerPage, dockable): real engine mixer. Keep APIs.
  * Browser     (left dock): categories All / Current Project / Samples / Audio /
                MIDI / Instruments / Effects / Plugins / Presets / Favorites /
                Recent; search; real metadata + waveform preview for audio
                (SndFile read, honest), preview play through the engine's real
                clip-playback path, drag/drop inserts real Session clips/notes.
  * Inspector   (right dock): context-sensitive properties for the current
                selection (playlist clip/track, mixer strip, piano-roll note);
                live Session-backed fields where the schema supports editing,
                read-only where it does not.
  * Plugin      (architecture + discovery UI only, §27-29): category views
                Built-in/External/User/Favorites/Recent + naming conventions
                for a future VST3/LV2 bridge. NO fake DSP, NO fake plugin
                windows. Honest empty-states with descriptions.

Workflow with dock pragmatics:
  * DockWidgets: PlaylistDock (central, non-closable core), BrowserDock L,
    InspectorDock R, MixerDock B, PianoRollDock (F), ChannelRackDock (F).
  * Every dock: closable/movable/floatable; tab-able; geometry + visibility +
    splitter sizes persisted (QSettings, versioned) with out-of-screen recovery.
  * Everything inside workspaces uses layouts/splitters only — no absolute
    positioning — so 1280x720→3840x2160 and 100–200% scaling never overlap.

Infrastructure:
  * theme tokens: full §38 set (matte surfaces, grid strong, clip-type colors,
    accent-active, violet playhead/loop, glass tuned more transparent+matte).
  * IconSet (branding/Icons.*): coherent vector glyph table for every command.
  * MisucCommandRegistry (ui/src/commands/): ID/Name/Description/Shortcut/
    Icon/Category/State/Value-provider/Trigger; single source for
    menu+toolbar+tooltip+HintBar+shortcuts+accessibility.
  * MisucTooltip (ui/src/tooltip/): premium glass hover surface, small delay,
    follows cursor, clamped to screen; text from CommandRegistry.
  * HintBar: promoted to registry-backed rendering (icon+name+description+
    value+shortcut), still poll-refreshed for live values.
  * HeaderBar: + workspace icon strip (Playlist/PianoRoll/ChannelRack/Mixer/
    Browser/Inspector), snap + song/pattern + live time in TransportBar,
    menus restructured to FILE/EDIT/ADD/PATTERNS/VIEW/OPTIONS/TOOLS/HELP.
  * Linux branding: .desktop StartupWMClass, scalable/512 icon install rules.
  * .deb: CPack DEB; verify with desktop-file-validate + dpkg-deb --info/.

-------------------------------------------------------------------------------
4. DESIGN SYSTEM SUMMARY (§36-38, §44, §66-68)
-------------------------------------------------------------------------------
- Palette: charcoal-black (#0d121b family), smoked translucent glass, matte
  surfaces, restrained violet accent (default accent #8f7bfa family), positive
  status stays kOk (readability + backward compat), violet playheads/loop.
- Icons: 1.4px-line coherent vector set, painted from theme tokens.
- Radii: small and controlled (2–8px); high density (§68); no huge controls.
- Glass: subtle depth layers (background → workspace → glass → elevated →
  active); graceful opaque fallback without GPU (§46).
- Typography: uiFont(10)/monoFont for numerals/positions/times.
